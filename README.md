# EDITORS.Wirelist — Wirelist & Cable Schedule Editor

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Wirelist & Cable Schedule Editor: comprehensive facility wire schedule manager; tracks wire numbers, cable types (Belden, Mogami, Gepco, Cat6A), lengths, origins, destinations, pull boxes, and termination status.

| | |
|---|---|
| **Opens** | the OS shell (Design → Cables & Wiring), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/EDITORS/EDITORS.Wirelist/` |
